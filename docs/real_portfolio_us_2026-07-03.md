## A/B/C QAOA 改进结果

### A. p=1 更充分搜索

使用60次优化迭代、3次内部随机重启，并将设备端 `top_k` 从4096提高到65536。
第一个种子（42）已命中精确基态：

| 项目 | 结果 |
|---|---:|
| 精确 / QAOA 原始QUBO能量 | -0.361293309252285 |
| 绝对 gap | 0 |
| 优化时间 | 1679.64秒 |
| 总时间 | 1684.95秒 |
| 最优 bitstring 概率 | 1.0186e-7 |
| 最优 bitstring 是否在 top-65536 | 是 |

### B. p=2 真 warm start

求解器现在会保存 `best_params`，并支持把最佳 p=1 参数经 INTERP 扩展为
p=2 的显式初值；后续不同种子只在该初值附近加入微小可复现扰动。该路径已实现
并配置好，但本轮未执行 p=2：p=1 已达到数学全局最优，p=2 不可能取得更低能量，
所以提前停止后续冗余GPU任务。

### C. Hamiltonian 数值缩放与诊断

原始系数最大值为 `max(|h|, |J|)=0.5014479824`。QAOA 训练时统一除以该正数，
使最大系数为1；这只重标定 cost angle `gamma`，不改变任意 bitstring 的排序。
最终比较和报告始终使用未缩放原始QUBO能量。

## 解释边界

本结果中的“QAOA命中基态”来自 GPU 全态矢量模拟后，在概率最高的65536个状态中
选择能量最低的可行状态。基态概率约 `1e-7`，并不意味着真实量子硬件用少量 shots
就会高概率测到它。SA 仍保留为生产兜底和经典基线。

当前回测仍是价格方向实验，未纳入手续费、滑点、资金费率、保证金、强平、合约
乘数、基差与移仓；不能当作实盘可实现净收益。
